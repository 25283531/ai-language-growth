# prompts/planner — Planner Prompts (versioned)

Versioned prompts for the planner role. The planner reads learner state, sets a goal, and organises the next activity — then the orchestrator executes it and the assessor judges the response.

Planner decisions are deterministic rules + LLM reasoning, never LLM-only, and every plan step must be traceable to learner evidence.
