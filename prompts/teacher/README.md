# prompts/teacher — AI Teacher Prompts (versioned)

Versioned prompts for the AI teacher role (one of four roles — planner / teacher / assessor / mentor — all via one LLM with different prompts and tools, not four separate models).

Prompts are versioned and reviewed like code. Fixed teacher persona: patient, gentle, encouraging, no mocking, no rushing, honest AI identity. Teaching style grows with the child's stage (early gentle tutor → interactive guide → English partner); growth is teaching method, not emotional dependency.
