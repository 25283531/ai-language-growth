# packages/curriculum — Curriculum Content

Dual-track curriculum content and structure: language acquisition (listening, speech discrimination, pronunciation, vocabulary, expression, dialogue) + school English (letters, phonics, word recognition, reading, spelling, grammar, simple writing).

Standards: CEFR Pre-A1 start, A1 as first-stage capability reference (not a timetable) + China 2022 Compulsory Education English Curriculum Standard. 7 growth stages (0启蒙适应 to 6自主日常交流). Textbook mapping is configurable by grade / publisher / version / unit — never hard-coded.

Content is AI-assisted generation with human review and versioning, especially pronunciation and phonics.
