# apps/web — Web Teaching Workbench (M1)

Next.js teaching workbench for the child learner. Web-first validation carrier in M1.

Scope (M1): greetings, self-introduction, objects around the child. Teach / listen / evaluate / adjust / record must all run end to end.

Constraint: teaching logic lives in the backend. This client only renders what the backend decides and captures the child's response (voice, tap, follow-read). No vendor or model names in client code.
