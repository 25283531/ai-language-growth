五项目核实：哪些是真的，
哪些能直接复用

对 FreeLingo、HiKid、Kid English Reading、Cadence、LinkPal / SpeakPal 五个说法逐个上 GitHub 和官网实开核实。结论不按二手转述算：只有两个项目按所称形态真实存在；一个查无实据；一个是三个同名产品被拼成了一个；一个被宣称的“ESP32 + 网页 + 开源服务端”组合根本不存在。

核实方式：2026-11-06 实开页面查验，约 16:25 UTC（America/Chicago） 对照基准：V1.1 — 6–9 岁零基础 · Pre-A1→A1 · 双轨 · 学习者模型 · 音素评估 · 慢速 TTS · L0–L3 路由

点任意一张卡，跳到该项目的完整核实条目。

给 V1.1 的一句话结论

没有一个项目能整机搬进来。能引入的是零件和模式：FreeLingo 的 CEFR 结构与服务商抽象、HiKid 的本地语音链路、xiaozhi-esp32 的 ESP32 语音协议（替代那个不存在的 LinkPal 基准）。学习者模型、五种掌握状态、慢速拆读、音素评估、L0–L3 路由、双轨课程——五个项目里都没有，仍须自研。

  • 儿童友好的语音优先 UX：只说不打字、故事与单词游戏
