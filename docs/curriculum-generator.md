# 独立课程内容生产服务

课程内容生产服务由 `alg-curriculum-generator` 独立容器运行，和后端、管理后台共用 `deploy/docker/docker-compose.yml`。容器不暴露宿主端口，只加入 `alg-net` 内网；管理员通过后台“课程管理”页面使用自然语言描述和词表调用。

生成流程如下：

1. 后端把管理员提交的等级、教材信息、词汇和自然语言要求转发给生成容器。
2. 生成容器先通过后端内部令牌调用小参数文本模型，整理 IPA、中文释义、音节、短语、儿童例句和发音难点。
3. 小模型不可用时，后端网关自动按主文本模型的供应商优先级处理。
4. 生成容器再调用主文本模型，按 CEFR 等级、七阶段教学体系和能力节点生成可验证活动。
5. 图片只接受模型给出的公开 HTTPS 资源建议。容器会拒绝内网地址、明文 HTTP、重定向到内网地址、非图片内容和超过 4 MB 的文件，并把可下载图片放入 ZIP 的 `assets/images/`。
6. ZIP 根目录包含 `curriculum-package.json`。管理员下载后可在同一页面导入，导入结果进入人工审核队列，审核通过后才能发布。

部署时只需要在 `.env` 设置：

```text
CURRICULUM_GENERATOR_TOKEN=自行生成的随机长字符串
```

该令牌只用于后端和生成容器的内网调用，不提交 GitHub。模型供应商、模型优先级、超时和凭据仍在管理后台的“模型接入”页面配置；生成容器不保存供应商密钥。

生成接口和课程包下载接口只监听容器内网，并要求 `x-curriculum-token`。管理后台通过后端代理下载，不应把 `3200` 端口映射到公网。
