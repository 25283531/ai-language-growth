# P1-4 家长门与孩子端敏感入口隔离

> 日期：2026-11-12
> 范围：Android 客户端「我」页的家长区。目标是用一道两位数乘一位数的家长验证，隔离注销账号、隐私协议和未来的会员支付入口；孩子端默认不显示这些入口。
> 结论：雷电模拟器上的功能验收通过。该家长门是**客户端交互摩擦**，不是服务端身份认证，也不替代账户权限校验。

## 2. 验证规则

家长区默认锁定。点击「家长验证」后：

1. 随机生成 `A ∈ [12, 99]`、`B ∈ [2, 9]`，显示 `A × B = ?`。
2. 答案输入框只保留数字，最多 4 位；空答案时「解锁家长区」不可点击。
3. 输入与 `A × B` 完全相等时：
   - 将本次运行期的 `parentUnlocked` 置为 `true`；
   - 关闭验证弹窗并清空输入；
   - 显示隐私协议、支付占位和注销账号入口。
4. 答案错误时：
   - 显示「答案不对，请家长再试一道。」；
   - 清空输入并重新抽取一道题；
   - 保持锁定，不设置任何错误次数上限或冷却时间。
5. 点击「取消」直接关闭弹窗，清空输入，不改变锁定状态。

题目和答案全部在本地生成、校验，不调用后端。理论乘积范围为 `12×2=24` 到 `99×9=891`，4 位输入上限足够。

### 边界说明

- 这是**家长门（parental gate）**，用于降低孩子误触概率，不是密码、PIN 或服务端角色校验。
- 会做两位数乘一位数的孩子可以通过；不能把它宣传为「防止孩子进入」的安全边界。
- 解锁后，注销请求仍以当前登录 token 的身份执行；服务端没有额外的「家长身份」校验。
- 当前没有解锁审计日志，也没有自动超时锁定。

## 3. 解锁生命周期

`parentUnlocked` 是 Compose 的内存状态，未写入 SharedPreferences、数据库或 token。它独立于 `childTheme`：切换主题不会改变家长区锁定状态。

| 事件 | 预期状态 | 本轮验证方式 |
| --- | --- | --- |
| 首次进入 / 冷启动 | 锁定 | 模拟器实测 |
| 应用进程被杀后重新打开 | 锁定 | `force-stop` 后重新启动，实测锁定 |
| 手动点「锁定家长区」 | 立即锁定 | 模拟器实测，三个敏感入口消失 |
| 退出登录 | 重置为锁定 | 代码检查；未实际退出，避免丢失测试登录态 |
| 修改密码成功 | 重置为锁定并清除 token | 代码检查；未实际改密 |
| 注销账号成功 | 重置为锁定并清除 token | 代码检查；未实际注销 |
| 仅切到后台再回来 | 同一进程内预计保持解锁 | 未单独实测 |
| 屏幕旋转 / 分屏 / Activity 重建 | 当前实现使用 `remember`，预计回到锁定 | 未实测；见第 6 节 |

当前没有空闲超时。家长解锁后把手机交给孩子，敏感入口会一直可见，直到手动锁定、退出登录、改密、注销或进程重启。若产品要求「离开页面即锁定」或「N 分钟自动锁定」，需要另行实现。

## 4. 孩子端隐藏清单

锁定状态下，家长区只显示说明文字和「家长验证」按钮。敏感入口不渲染，而不是渲染后置灰或隐藏点击区域。

| 入口 | 孩子端（锁定） | 家长端（解锁） |
| --- | --- | --- |
| 家长区说明 | 显示「仅家长可操作」 | 显示「本次运行期已解锁」 |
| 家长验证 | 显示，可打开验证弹窗 | 替换为「锁定家长区」 |
| 隐私协议 | **隐藏** | 显示，进入隐私协议页 |
| 家庭会员与支付（即将开放） | **隐藏** | 显示，点击只显示占位提示 |
| 注销账号 | **隐藏** | 显示，点击进入二次确认 |
| 偏好与协议 | 显示 | 显示 |
| 切换成人主题 | 显示 | 显示 |
| 用户协议 | 显示 | 显示 |
| 账户 / 退出登录 | 显示 | 显示 |

补充说明：

- 「用户协议」仍对孩子可见；P1-4 只要求隔离注销、隐私协议和支付。如果产品希望协议入口也全部由家长控制，需要单独确认，不能默认扩大范围。
- 隐私入口回调也检查 `parentUnlocked`：未解锁时即使被程序化触发，也只显示「请先完成家长验证」，不会进入隐私页。
- 注销回调同样检查 `parentUnlocked`；注销确认弹窗额外要求 `parentUnlocked && confirmDelete`，锁定后不会保留可确认的注销弹窗。
- 支付入口只在解锁分支渲染。点击后仅设置「支付入口尚未开放，本次不会扣款」，没有支付 SDK、订单、扣款或外部跳转。

## 5. 模拟器实测记录

以下结果来自 `uiautomator dump` 的界面文本与控件状态，不是仅根据源码推断。

| # | 场景 | 实际操作 | 观察结果 |
| --- | --- | --- | --- |
| 1 | 初始锁定 | 进入「我」→ 滚动到家长区 | 仅显示家长区说明和「家长验证」；无隐私协议、支付、注销账号 |
| 2 | 正确答案 | 题目 `98 × 5 = ?`，输入 `490` | 弹窗关闭，出现「隐私协议」「家庭会员与支付（即将开放）」「注销账号」「锁定家长区」 |
| 3 | 支付占位 | 解锁后点击支付入口 | 页面底部显示「支付入口尚未开放，本次不会扣款」；未发生支付跳转 |
| 4 | 隐私协议 | 解锁后点击隐私协议 | 进入隐私协议页，显示监护人陪同阅读提示和条款正文；可返回 |
| 5 | 注销二次确认 | 再次解锁（`84 × 6 = 504`）后点击注销账号 | 显示「确认注销账户？」「注销后将无法登录，学习账户也会停用。」；点击「返回」取消，未实际注销 |
| 6 | 错误答案 | 题目 `27 × 7 = ?`，输入 `190`（正确值为 `189`） | 显示「答案不对，请家长再试一道。」；输入清空，题目变为 `67 × 7 = ?`，仍保持锁定 |
| 7 | 手动锁定 | 解锁后点击「锁定家长区」 | 三个敏感入口立即消失，恢复「家长验证」 |
| 8 | 进程重启 | `force-stop` 后从桌面重新启动，进入「我」→ 家长区 | 自动恢复锁定；已有登录态仍在，未要求重新登录 |
| 9 | 取消验证 | 打开家长验证后点击「取消」 | 回到锁定状态，未解锁 |

结论：在上述模拟器与构建上，P1-4 的锁定态、正确答案解锁、错误答案刷新、支付占位、隐私页、注销确认、手动锁定和进程重启自动锁定均符合预期。

## 6. 未覆盖的真实设备与上线验证项

本轮只在一台雷电模拟器上验证，以下项目尚未覆盖，不能据此宣称「全设备通过」：

- **物理 Android 设备**：另一台已连接设备未安装本轮包，未验证厂商 ROM、系统 WebView、输入法和返回键差异。
- **屏幕形态**：横屏、分屏、小屏、折叠屏、字体放大、显示大小调整下的弹窗完整性和按钮可达性。
- **Activity 重建**：当前 `parentUnlocked` 是 `remember` 状态，旋转/分屏/语言或字体变更导致重建时预计回到锁定；未实测。若要在同一前台会话内保持解锁，应使用 Activity 级 ViewModel（进程死亡时自然重置）；不建议改用 `rememberSaveable`，因为它可能跨进程恢复，与「重新打开应用后自动锁定」冲突。
- **无障碍**：TalkBack 下弹窗标题、题目、输入框、错误提示的朗读顺序与焦点陷阱；未验证。
- **输入法**：`GrowthTextField` 当前没有设置数字键盘类型，部分输入法可能弹出全键盘；孩子端实际输入体验未在真机验证。
- **真实支付**：当前只有占位提示，没有支付 SDK、服务端下单、价格校验、回调幂等、退款和监护人同意流程；真实支付必须另立任务验收。
- **真实注销**：只验证了确认弹窗，没有执行服务端注销，因此账户删除、数据保留策略、审计记录和注销后重新注册均未验证。
- **退出登录 / 改密后的锁定重置**：代码路径已检查，但为避免破坏测试账号，未做端到端操作。
- **主题切换与家长区独立性**：代码上 `parentUnlocked` 与 `childTheme` 分离，未做端到端主题切换验证。
- **绕过测试**：未测试 adb、无障碍服务、改包、深链或 root 场景。该门本身不承诺抵抗这些能力。
- **长时间后台/前台切换**：没有自动超时，未验证长时间保留解锁态的产品接受度。
