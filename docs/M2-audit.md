# M2 交付核查

按《AI Language Growth Platform V1.1 总体设计与开发任务书》第 8 章 M2 范围核查。此清单区分代码实现和需要真实儿童样本才能完成的实测验收。

| M2 要求 | 状态 | 说明 |
| --- | --- | --- |
| 多维能力档案、学习证据与掌握状态 | 已有基础实现 | M1 已有按能力节点分轨的证据、状态和迁移规则；阈值仍未用儿童样本校准。 |
| 复习与能力迁移 | 已实现 | 到期复习、无提示提取、跨场景候选和间隔调整已完成。 |
| 长期记忆与成长档案 | 部分实现 | 结课结构化摘要、快照和 Web 查看已完成；管理 API 与 Web 管理页可纠正/删除记忆；偏好自动提取、监护人专用授权和记忆检索策略仍缺。 |
| 受控教师人格管理 | 部分实现 | Web 管理页支持白名单风格参数、版本历史和回滚；运行时应用可调参数，安全核心固定。审批流程、按学习者个体适配与真实效果验证仍缺。 |
| 教学规划引擎 | 部分实现 | 主题活动规则、到期复习、隔天跨课进度恢复及薄弱技能优先已完成；长期学习计划、策略效果反馈仍缺。 |
| L1—L3 智能路由 | 未完成 | 目前使用代码内默认规则；数据库任务路由尚未成为运行时配置，服务商配置也未按等级分别接入。 |
| 儿童专项 Model Benchmark 门槛 | 代码已实现 | 后台可登记服务级测试结果；未通过或无样本记录的已配置模型保持 Mock。实际测试数据和模型等级准入仍需真实儿童样本。 |
| ASR / TTS / 发音评估分级 | 未完成 | ASR 有可疑结果二次识别基础；三类服务的等级配置、质量门槛与统一升级/降级闭环未完成。 |
| 成本预算与自动降级 | 部分实现 | 用量已持久化；真实价格计量、路由预算熔断及依据预算自动选择备用模型未完成。 |
| 隔天重进后延续教学并调整策略 | 代码已实现 | 新课堂读取最近成长快照，沿用上次主题上下文，并优先安排失败多于独立成功的技能复习；真实儿童效果仍需实测。 |

代码节点按功能分别提交到 GitHub，并以 GitHub Actions 验证；不在本机执行构建或测试。

## 仍需外部实测的验收

- 使用不同年龄、口音和基础的真实儿童样本评测 ASR 与音素级发音评估，并标定阈值。
- 用真实儿童教学测试检验低成本模型质量、教师耐心换法和稳定迁移结果。
- 实测单轮语音延迟目标（1—2 秒）及供应商实际账单价格。
