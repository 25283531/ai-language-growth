## Embedding 与 Rerank

- **Embedding：需要，已加入配置目录。** 它是 Mem0 语义检索和 L5 课程知识 RAG 的基础配置。当前后台可保存服务商、模型、自定义接入点、加密凭据和参考单价；页面明确说明检索调用链尚未启用。预置百炼、硅基流动、Ollama 和 OpenAI 兼容端点。
- **Rerank：暂不接入。** 当前没有向量召回链路、候选集规模或检索误差数据，无法证明重排会提高教学正确性。第一版可先用元数据/用户隔离过滤、向量召回和小候选集；等检索评估显示排序错误显著影响记忆或课程命中率后再加入。
- 这次只完成 Embedding 的管理配置，不等于已完成 Mem0、向量存储、检索、删除/重建、Embedding 计量或 RAG。启用教学检索前必须补齐这些实现和隔离验收。

## 发音评测接入建议

1. **不要把所有供应商 SDK 放入 APK。** 原生 SDK 会增加 APK 体积、权限、初始化和兼容维护成本。服务端模型设置也不能切换一个 APK 中不存在的 SDK。
2. **采用一个经真机与儿童样本验证的 Android 主 SDK，其他候选保留服务端适配器。** 腾讯 SOE Android AAR 已由用户提供，可作为端侧试点；Tencent 长期 SecretKey 不进入 APK。官方 SDK 支持外部签名，也支持使用服务端取得的临时凭证，但短期凭证在有效期内通常可重复使用，不等于单次评测授权。服务端验证账户/会员并预留额度后，若无法取得真正单次或限额凭证，需按可重放窗口保守扣减，或把该调用留在服务端网关。
3. **厂商接入形态不同。** 用户提供的腾讯包是 Android AAR 与 iOS XCFramework；阿里 SSECP 是端侧 SDK，`warrantId` 在有效期内可能重复使用，且当前模型预置目录没有阿里口语评测项；讯飞 ISE 需要按当前账号开通能力核实 HTTP/流式接口和 SDK 版本；Azure Speech SDK 可返回词、音节、音素结果；Speechace 是上传音频与目标文本的 REST API。不能用一个统一客户端调用假设覆盖所有厂商。
4. **当前代码尚不能实现“后台选择供应商后 APP 自动切换 SDK”。** `ai_provider_configs` 对每个 `serviceKind` 只有一条配置；Gateway 每个服务也只注册当前单个配置。Android 正式客户端尚无发音 SDK 和服务端供应商授权获取链路。要做服务端控制的主备，后续需支持多供应商模型注册/路由、主备健康策略、客户端能力协商、供应商授权签发与额度结算，并验证 SDK 凭证的重放边界。
5. **讯飞当前有一项发布阻塞。** 当前预置和 `IflytekIseAdapter` 使用 `api.xfyun.cn/v1/service/v1/ise` HTTP 地址；在没有按实际账号核对当前可用接口、签名方式、SDK 版本和返回格式前，不应把现有讯飞配置作为生产可用发音评测。若账号要求迁移到流式接口，需要单独补充 WebSocket 适配器和真机验证。

## 后续顺序

1. 补齐课程活动与学校英语双轨内容，把外部课程包审核导入，并逐级核对技能节点、活动、答案和证据映射。
2. 完成 L1 Redis 工作记忆；为 L3 实现 Mem0/语义检索和用户隔离；为 L5 实现课程知识库索引、检索、版本更新及删除重建。Embedding 管理配置已先行准备。
3. 迁移讯飞 ISE 普通版到流式 WebSocket，并用接口集成验证结果解析和音素粒度。
4. 设计 Android 发音 SDK 凭证签发和供应商下发 API；以腾讯 SDK 做独立云构建 APK 原型，先验证短期授权和额度重放边界，再用真实 6-9 岁儿童样本决定主用/备用。
5. 建立按年龄、口音、熟练度分层的儿童样本集，校准评测阈值、模型路由、阶段迁移和教师风格效果。
